## harmony/cylliquidglass/src/main/ets/CYLLiquidGlass.ets

Liquid Glass as a base library for HarmonyOS NEXT, the counterpart of iOS `CYLLiquidGlass` / `CYLLiquidGlassView` and
     Android `com.cyl.liquidglass`: the availability rule `CYLLiquidGlass.isActive()`, the glass material and capsule the tab
     bar draws, and `CYLLiquidGlassView`, a glass background for any component. API 12 to 21 have no system glass material,
     so the glass is a blur with a light or dark tint, as in the tab bar.
     `CYLLiquidGlass.isActive()`、TabBar 绘制的玻璃材质与胶囊，以及 `CYLLiquidGlassView`（任意组件的玻璃背景）。API 12 到 21 没有系统玻璃
     材质，因此玻璃使用模糊加浅色或深色着色，与 TabBar 相同。

- `export class CYLLiquidGlass` (L18)
  Whether Liquid Glass is drawn, the one rule every CYLTabBarController component asks (the same name as iOS and Android):
       always on HarmonyOS, whose tab bar draws the blur imitation on every supported API (the system material replaces it from
       API 24); `activeOverride` replaces it in tests.
       API 上都绘制模糊仿制（系统材质从 API 24 起替代它）；`activeOverride` 供测试替换。

- `static activeOverride: boolean | undefined = undefined;` (L22)

- `static isActive(): boolean` (L28)
  Whether Liquid Glass is in use (see the class comment); when false the caller keeps its flat background.

- `export struct CYLLiquidGlassView` (L44)
  A Liquid Glass background for any component (the same name as iOS `CYLLiquidGlassView`): put it behind the content in a
       `Stack`. The pages behind it are blurred inside the rounded rectangle and tinted with `glassTintColor` (a color string such
       as '#66FF8800'; '' for none). It takes no touches and is hidden from accessibility. When `CYLLiquidGlass.isActive()` is
       false the caller keeps its flat background and does not create the view.
       `glassTintColor`（颜色字符串，如 '#66FF8800'；'' 表示不着色）着色。不接收触摸，对辅助功能隐藏。`CYLLiquidGlass.isActive()` 为 false 时，
       调用方保持其扁平背景，不创建该视图。

- `export class CYLLiquidGlassMaterial` (L77)
  The glass material, with the reference's compatibility rule: never create a material at module level or in a field
       initializer, and fall back to a blur where the system material does not exist. On the SDKs this port builds with

- `static blurFallback(strength: number): BlurStyle` (L82)
  The fallback blur for a material strength 1 (thickest) to 5 (thinnest), as the reference's blurFallback.

- `export class CYLLiquidGlassCapsuleModifier implements AttributeModifier<RowAttribute>` (L98)
  The glass capsule (the expanded bar and the minimized ball): the fallback blur, the app's bar tint when it set one,
       the material's shadow and a light rim for the highlight; the radius makes it a capsule at any height.
