## android/scripts/android_public_api.py

Android -> iOS API table: every public symbol of the Android core and its iOS counterpart.
android_public_api.py          write docs/android-ios-api.md
android_public_api.py --check  exit 1 when docs/android-ios-api.md is out of date
Android symbols are the public declarations of android/merged/library (class / interface / object / enum class, their
public `fun` / `val` / `var` members and enum entries, and top-level `fun` / `val`). A symbol has an iOS counterpart
when (1) android/merged/api-map.json maps an iOS symbol to it (the iOS -> Android table, docs/android-api.md), or
(2) android/merged/ios-map.json names one by hand, or (3) the iOS Swift core (CollectionViewClassifyMenu/Class,
TagCollectionView) declares a type or member of the same name. Everything else is `TODO`.

## android/scripts/api_map_from_kotlin.py

Add to android/merged/api-map.json every iOS symbol whose same-named Kotlin API exists in com.cyl.classifymenu.
api_map_from_kotlin.py            add the verified mappings, print what is still missing for ported classes
api_map_from_kotlin.py --dry-run  print only
A symbol maps only when the Kotlin source declares it: a class / interface / object / enum of the same name, a member
(`var`, `val` or `fun` of the property name or of the selector's first keyword) declared in that type's file, an enum
entry, or a top-level `const val` / `val` / `fun`. Existing entries are kept. Initializers and other renamed members
are mapped by hand in api-map.json.

## android/scripts/gradle.sh

Runs Gradle for one project in android/ from a mirror under /tmp: Gradle fails on the macOS `._*` files this
volume creates. Usage: android/scripts/gradle.sh <android-tagview|TagViewGroup|AndroidTagView|merged> <tasks...>
ANDROID_MIRROR (default /tmp/xpa/android), ANDROID_JAVA_HOME (a JDK 17; default ~/develop/jdk/jdk-17.0.21+9,
else JAVA_HOME) and ANDROID_HOME are used when set.

## android/scripts/ios_public_api.py

iOS -> Android API table: every public symbol of the iOS core and its Android counterpart.
ios_public_api.py --list          print every public iOS symbol, one per line
ios_public_api.py                 write docs/android-api.md
ios_public_api.py --check         exit 1 when docs/android-api.md is out of date
The iOS core is Swift since the migration (docs/Swift-Migration.md): the symbols are the public / open declarations of
CollectionViewClassifyMenu/Class and of the podspec's TagCollectionView files (types, properties, methods with their
Objective-C selector, enum cases, global constants and functions). Protocol conformance (UIKit data sources and
delegates, and the library's own delegate protocols implemented by its classes) is left out, as the Objective-C headers
did. A symbol has an Android counterpart when android/merged/api-map.json maps it (by its key, or by the key the same
symbol had in the Objective-C headers), or when the Android core (android/merged/library) declares the same name on the
same type. Everything else is TODO. Score = symbols with a counterpart / all symbols x 100.

## android/scripts/sync_merged_sources.py

Copy the three Kotlin libraries into android/merged/library, unchanged except for the R import.
The merged library has one namespace (com.cyl.classifymenu), so the classes of the three original packages
(me.kaede.tagview, co.lujun.androidtagview, com.licrafter.tagview) import that R. Run it after changing a library in
android/android-tagview, android/AndroidTagView or android/TagViewGroup; --check reports differences and exits 1.
