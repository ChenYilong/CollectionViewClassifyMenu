## harmony/entry/src/main/ets/animation/CYLExampleAnimationViews.ets

The example's animation engines: `cylRegisterExampleAnimationEngines()` registers CYLTabBarController's engine views
(`CYLAnimatedItemLottie`, `CYLAnimatedItemPAG`, `CYLAnimatedItemRive`, `CYLAnimatedItemGIF`, `CYLAnimatedItemSVGA`), so every
tag's animated icon plays through `CYLAnimatedItemView`'s default engine view (the tag drives the player: resting
progress, Play all, speed, loop). The example's own players and views are gone (docs/animated-item-migration.md):
every engine fix now lives in CYLTabBarController and is shared by the apps that use it.

- `export function cylRegisterExampleAnimationEngines(context?: Context): void` (L18)
  Registers the engines the example plays (Lottie, PAG, Rive, GIF, SVGA). Called once, before any tag is shown
  (`EntryAbility.onCreate`). With the ability's context, the x86_64 debug engine kit is read first (PAG and Rive then play on
  the x86_64 emulator in debug builds).

## harmony/entry/src/main/ets/demos/menu/CYLTagAnimationPage.ets

`CYLTagAnimationDemoViewController` (动效图标): the animations and images of CYLTabBarController's examples, one
section per library, created from a dictionary (map) configuration; a tap plays the tag's icon. The playback
controls of docs/example-demo-rules.md: Play all (全部播放), a speed slider (0.25x to 4x, steps of 0.25, the value next
to it) and a loop switch (循环播放); they combine and act at once, also on icons that are playing.
HarmonyOS: each tag's icon is CYLTabBarController's CYLAnimatedItemView; the library depends on no animation
library, and the example registers the engines it bundles and their views (animation/CYLExampleAnimationViews.ets,
called from EntryAbility), picked by the file's extension: Lottie (@ohos/lottie), PAG (@tencent/libpag), Rive
(@ohos/rive), SVGA (decoded by the example), GIF (frames decoded by ImageKit). The files are rawfiles (pag/, rive/,
svga/, gif/); every Rive scene has an SVGA twin (svga, svga-dark), with the same Rive
options and PAG resting progress as iOS. Rive has no playback speed on HarmonyOS (CYLTabBarController's
`CYLRiveAnimationBuilder`, driven through CYLAnimatedItemView's own props).
