## CrossPlatform/wechat-miniprogram/scripts/export-animations.py

Exports the iOS example's animated and static tag icons to the Mini Program (miniprogram/data/animations and
miniprogram/images/styles), for the Styles, Animated icons and Configuration screens:
- Lottie files of Example/CYLMenuExample/CYLMenuExample.bundle/Animations/Lottie -> data/animations/lottie/<name>.js
(a Mini Program can `require` only JavaScript; image assets are embedded as data URIs). The four tab_*_animate.json
files are the ones of data/lottie/*.js (scripts/export-miniprogram-data.py), so the registry reuses those modules.
- GIF files -> data/animations/gif/<name>.gif, with the first and last frames as PNG (the resting and the selected
frame: an <image> plays a GIF on its own) and the duration of one pass.
- SVGA files -> engines/svga/<name>.svga.bin, in the "engines" subpackage next to CYLTabBarController's cyl-svga
(a code package leaves out .svga files).
- the configuration file Configurations/animated-tags.json, copied as is.
- CYLTabBarController's tab images and the Lottie placeholders of Assets.xcassets -> images/styles/tab/<name>.png.
- data/animations/index.js: the registry, by the path the iOS example uses ("Lottie/tab_home_animate.json").
python3 scripts/export-animations.py           write the files
python3 scripts/export-animations.py --check   exit 1 when a written file differs from its source
Needs Pillow (the GIF frames).

## CrossPlatform/wechat-miniprogram/scripts/export-search-data.py

Exports the data of the search discover screen (CYLSearchDiscoverViewController) to the Mini Program:
- Example/CYLMenuExample/CYLMenuExample.bundle/<language>.lproj/search-discover.json (one file per language, the
same topics in the same order) -> miniprogram/data/search/search-discover.js, keyed by "zh-Hans", "zh-Hant", "en"
(a Mini Program can only `require` JavaScript);
- the localized hot icon <language>.lproj/discover-hot@3x.png -> miniprogram/images/search/discover-hot-<language>.png;
- the core's template images, tinted as the iOS screen tints them: cyl_more@3x.png (the More button,
secondaryLabel) -> images/search/more.png, cyl_fold_chevron@3x.png (the inline fold cell, CYLMenuStyle
foldControlColor = UIColor.gray) -> images/search/fold-chevron.png.
Run from anywhere: python3 CrossPlatform/wechat-miniprogram/scripts/export-search-data.py [--check]
--check fails (exit 1) when an exported file differs from what the sources give. Needs Pillow for the tinted images.

## CrossPlatform/wechat-miniprogram/scripts/verify-package.js

- `const { execFileSync } = require('child_process');` (L13)
  Checks the tag list library (packages/cyl-tag-list-miniprogram) as npm publishes it:
    1. `npm pack` writes the tarball to .deps/ (git-ignored);
    2. the tarball holds package.json, README.md, LICENSE and every file of miniprogram_dist, and nothing else;
    3. `npm install --no-save` installs the tarball into node_modules (a copy, not the file: link), and every installed
       file equals its source, so WeChat DevTools' "Build npm" builds miniprogram_npm from what users get.
    node scripts/verify-package.js           pack, check and install the tarball
    node scripts/verify-package.js --restore afterwards: install the file: link again (npm install)
