# Flutter and React Native wrappers

Per-declaration detail: api-reference/flutter-react-native-*.md. Both wrap the native lists; neither redraws tags.
A configuration map (same keys as the native configuration) is passed through. "asset:" strings are resolved per platform.

## Flutter (flutter/cyl_tag_list, cyl_tag_list_ohos)
- lib/cyl_tag_list.dart: CylTagListView and CylTagListController over a platform view (UiKitView; hybrid composition on
  Android) with a per-view method channel com.cyl.cyl_tag_list/view/<id>.
- iOS: CylTagListPlugin.swift hosts the Swift CYLTagListView in a container that reports width changes, then sends the
  content height. Android: CylTagListPlugin.kt hosts com.cyl:classifymenu. HarmonyOS: Dart sends configurationJSON to
  CylTagListOhosPlugin.ets, which hosts harmony/classifymenu. tool/patch_embedding_api21.py patches the OHOS embedding
  for older SDKs.
- The example's pubspec turns Swift Package Manager off for iOS (using both linked duplicate symbols), and its Podfile
  declares the core pod. A comment in that Podfile still says the core comes through Swift Package Manager: stale.
- _CylTagListViewState has no didUpdateWidget, so a new controller or configuration prop is not forwarded (may be by
  design; use controller.applyConfiguration).
- Example: tag animation page and a database classify page (same SQL as iOS; selections saved in the database).
  Android shows CYLTabBarController's native bar (flutter_cyltabbar); integration_test cannot tap it, so the test opens
  the tab directly. lib/strings.dart is generated by tool/export_strings.py from the iOS bundle.

## React Native (react-native/react-native-cyl-tag-list)
- Fabric component; the configuration travels as a JSON string. src/index.tsx, CylTagListView(.native).tsx, the native
  component spec, CylTagListConfiguration.ts (typed keys and value names).
- iOS: CylTagListView.mm + CylTagListBridge.swift (no prepareForRecycle). Android: CylTagListView.kt does manual
  measure and layout passes. Events: onTagTap, onTagLongPress, onSelectionChange (itemsJSON), onContentHeightChange;
  command playAll.
- Example: CYLTabBarController tab bar with a plus page; TagListPage, ClassifyPage (op-sqlite on the shared database),
  i18n.ts + generated dataStrings.ts, launchOptions.ts for screenshots. harmony-example/ is an RNOH shell with an ArkTS
  tab bar and CylTagListRNView.ets over harmony/classifymenu; setup.sh copies the library and pages, runs codegen,
  bundles. It reads rawProps because the generated selector returned them empty on RNOH 0.86.1.
- src/__tests__/index.test.tsx checks the wrapper passes props and unwraps events (no native code).
