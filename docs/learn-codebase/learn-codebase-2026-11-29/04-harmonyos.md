# HarmonyOS (harmony/)

Per-declaration detail: api-reference/harmonyos-library-part1.md to harmonyos-library-part4.md.

## harmony/classifymenu (@cyl/classifymenu)
- core/: types, tag model, appearance, colors, style, data source, cache, configuration, long press, metrics.
  CYLCoreStrings is generated by harmony/scripts/export-core-strings.py.
- components/CYLTagListState.ets: the UI-free model and controller (data, selection, fold, measurement,
  layoutSections() frames, cache and load, rename, smear, reorder, long press, RTL, configuration) plus button and fold
  metrics. This is what host tests drive. CYLTagListView.ets draws absolute frames inside a Scroll.
- ForEach keys are composite; Rive items keep frame-free keys because @ohos/rive crashes on dispose.
- Gestures: priority tap, parallel smear pan, long press followed by pan. Callout uses bindPopup.
  CYLMenuGestureState.shared lets containers stop scrolling during drag or smear.
- Colors are '#AARRGGBB' strings or ResourceColor. tagviews/CYLTagButton has explicit and built-in color channels
  feeding CYLAnimatedItemColorResolver; only an explicit color tints glass. Layout is a manual layoutSubviews over
  @Observed state.
- Cache: relationalStore (opens asynchronously, memory mirror), preferences, or JSON file.
- RTL layout is supported through layoutDirection. components/CYLTagListModel.ets also holds a legacy JSON
  parser (parseConfiguration, CYLTagSelection, foldedHeight).
- classify/: classify menu controller and view, left-aligned layout, filter base panel (backdrop blur, back-press hook
  hideShowingPanelForBackPress), multiple filter (throws on conflicting selection). imagetag/: timer animations, pure
  geometry in CYLImageTagModel, collision separation in CYLImageTagView.

## harmony/entry (example)
5-tab shell with a plus tab (pages/Index). EntryAbility registers Lottie / PAG / Rive / GIF / SVGA engines, reads launch
options (cylScreen, cylScreenParam, cylLanguage, cylColorMode) and stores cyl_colorMode in AppStorage for glass.
NavPathStack routes are named like the iOS classes. PlacesDatabase copies cyl_places.sqlite from rawfile.
Demos: menu linkage (SQL, source titles), query scenarios, tag animation / configuration / glass / style, reviews
(memory / network / SQLite), image tag, tag cloud, tag container, word picker, search category / discover / home.

## Build and test
- build-profile.json5 has an "emulator" target that leaves out arm64-only .so files (x86_64 emulator; install error
  9568347 otherwise). Rive and PAG playback need arm64.
- src/test: Hypium host tests on CYLTagListState with a fixed text measurer. src/ohosTest: accessibility-first UI tests.
- scripts: accessibility-check, build, check-native-strings, export-core-strings, export-example-strings,
  harmony_parity + parity_map, screenshots, ui-test (picks the emulator target), unit-test.
