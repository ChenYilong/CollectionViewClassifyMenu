# CrossPlatform

Cross-platform components and examples of CollectionViewClassifyMenu that do not live in their own top-level folder.
The layout follows CYLTabBarController's `CrossPlatform/` folder.

| Folder | Platform | Status |
| --- | --- | --- |
| [`wechat-miniprogram`](wechat-miniprogram/README.md) | WeChat Mini Program | In progress (see `docs/cross-platform.md`, "the WeChat Mini Program example") |

The Flutter plugin (`flutter/cyl_tag_list`) and the React Native component (`react-native/react-native-cyl-tag-list`)
keep their top-level folders, which their build scripts, CI and documents refer to.
